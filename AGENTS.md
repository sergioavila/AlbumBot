# Agent instructions

Read `CONSTRAINTS.md` before writing code. Do not weaken it to make a change
pass.

Read the active `.scratch/<feature>/HANDOFF.md` before resuming work and update
it before handing work off.

### Issue tracker

Issues and handoffs are tracked as local markdown under `.scratch/`. See
`docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical five-role vocabulary. See
`docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
